# Credit Scoring for Unbanked Populations Using Mobile Money Data

> **AI4Africa Community Project Initiative**

## Problem Statement
Over 350 million Africans are unbanked and invisible to traditional credit systems, locking them out of loans and economic opportunity despite having rich mobile transaction histories.

## Objective
To build a machine learning scoring model that evaluates synthetic or anonymized mobile money transaction patterns to assess creditworthiness for individuals without formal banking histories.

## Technical Stack
- **Language:** Python 3.x
- **Data Manipulation:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn, XGBoost
- **Visualization:** Matplotlib, Seaborn
